# Shine — гардероб

Прототип мобильного приложения (React 19 + Vite 8 + Tailwind v4), выгруженный из Figma Make.

## Запуск

```bash
npm install
npm run dev
```

Vite слушает `0.0.0.0:8443`, поэтому приложение сразу доступно в локальной сети.
В выводе `npm run dev` будет строка `Network: http://<IP>:8443/` — откройте её на телефоне,
подключённом к той же Wi‑Fi сети.

- На телефоне (ширина ≤ 500px) приложение открывается во весь экран.
  Узкая вкладка у правого края экрана открывает список всех экранов (только в dev).
- На компьютере приложение показывается в рамке iPhone, под ней — навигатор по экранам.
- `?frame=0` / `?frame=1` — принудительно выбрать режим, `#outfit-result` — открыть конкретный экран.
- Можно добавить на домашний экран iOS/Android («На экран „Домой“») — откроется без адресной строки.

Если телефон не открывает страницу: проверьте, что компьютер и телефон в одной сети,
и что macOS‑файрвол разрешает входящие подключения для `node`.

## Сборка

```bash
npm run build     # dist/
npm run preview   # раздаёт dist/ на 0.0.0.0:8443
```

## Структура

```
src/
  app/            App (оболочка), AppContext (навигация + состояние), routes (экран → компонент)
  navigation/     тип Screen и список экранов
  pages/          экраны по разделам: onboarding, home, outfit, wardrobe, saved, auth, profile, states, ui-kit
  components/
    ui/           базовые элементы: Btn, Tag, Img, Placeholder, Caption, Divider, BackBtn, OutfitPiece
    layout/       StatusBar, BottomNav
    shell/        рамка телефона, навигатор экранов, режимы отображения
    icons.tsx     SVG‑иконки
  constants/      картинки‑заглушки
  data/           моковые данные (гардероб, образы, ситуации, стили) — сюда подключать MCP/API
```
